# Pixiv for Aidoku

Aidoku source supporting Pixiv web login and refresh/access token login.

Add this source-list URL in Aidoku settings:

```
https://raw.githubusercontent.com/quiteQa/aidoku-pixiv/gh-pages/index.min.json
```

The source code and documentation are at https://github.com/quiteQa/aidoku-pixiv.
